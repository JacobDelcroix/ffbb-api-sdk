# Guides

Exemples commentés, par type de données. Pour la liste exhaustive des méthodes, paramètres et types,
voir la [référence API](../reference/README.md), générée depuis le code.

| Guide | Contenu |
|---|---|
| [01 — Démarrage](01-demarrage.md) | Installation, création du client, jetons, forme des données |
| [02 — Clubs et équipes](02-clubs-et-equipes.md) | Trouver l'identifiant d'un club, ses équipes engagées, ses contacts |
| [03 — Compétitions, poules, classements](03-competitions-poules-classements.md) | Compétitions, phases, poules, classement, saisons |
| [04 — Rencontres et listes](04-rencontres-et-listes.md) | Matchs, calendriers, résultats, pagination, lives, données partenaires |
| [05 — Recherche](05-recherche.md) | Meilisearch : texte, filtres, géolocalisation, recherche universelle |
| [06 — Query builder Directus](06-query-builder-directus.md) | Tous les paramètres Directus sur n'importe quelle collection |
| [07 — DTOs](07-dtos.md) | Objets typés générés depuis la spec OpenAPI |
| [08 — Erreurs, cache et repli](08-erreurs-cache-et-repli.md) | Exceptions, valeurs `null`, retry, WAF, Meilisearch de secours, cache |
| [09 — Laravel](09-laravel.md) | Service provider, façade, config, Actions, tests |

Les identifiants utilisés dans les exemples (`10238` = Ostrevent Basket Ball EAA Monchecourt) sont réels ;
les identifiants de poules et de rencontres (`900`, `'r1'`…) sont des exemples à remplacer.
